Bank Statement
Manager

Importe, organize e consulte extratos bancários de diferentes formatos em uma única base de dados local. Consolide movimentações financeiras, realize pesquisas e verifique lançamentos de diferentes contas bancárias de maneira prática e organizada.

Baixar BSM para Windows Ver código no GitHub

Funcionalidades

Recursos para centralizar, consultar e analisar informações de extratos bancários.

Múltiplas contas bancárias

Cadastre e organize diferentes contas bancárias em uma mesma aplicação.

Importação de extratos

Importe movimentações de planilhas Excel nos formatos XLS e XLSX.

Layouts configuráveis

Configure a estrutura dos extratos para interpretar corretamente arquivos de diferentes bancos.

Controle de duplicidade

Identifique lançamentos já importados para evitar duplicações entre períodos sobrepostos.

Consultas e filtros

Pesquise movimentações utilizando filtros combinados de data, descrição e valor.

Exportação de resultados

Exporte os resultados das consultas para planilhas Excel.

Tecnologias

Desenvolvido em Python, com interface gráfica e armazenamento local de dados.

Python PySide6 / Qt SQLite openpyxl xlrd PyInstaller

Download para Windows
